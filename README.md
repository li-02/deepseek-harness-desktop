# DeepSeek Harness Desktop

[简体中文](README.md) | [English](README_EN.md)

DeepSeek Harness Desktop 是一个 Windows 桌面应用，让你不用懂任何编程，就能在电脑上使用 DeepSeek Harness —— 一个强大的人工智能助手工作台。安装后打开就能用，它会自动帮你把一切准备好。

## 它能为你做什么

- **打开即用**：不需要安装 Node.js 或任何开发环境，装上就能用。
- **用起来像普通软件**：启动后自动打开 Harness 工作台窗口，窗口大小和位置会自动记住。
- **自动更新**：后台自动检查并更新核心组件，不用你手动操作，重启应用即生效。
- **更新失败自动回滚**：万一更新后打不开，会自动恢复到上一个能用的版本。
- **数据不丢失**：设置、会话和日志单独保存，更新不会清掉你的数据。
- **单窗口运行**：重复启动只会聚焦已有窗口，不会开一堆后台实例。

## 下载与安装

到 [Releases 页面](https://github.com/li-02/deepseek-harness-desktop/releases) 下载最新的 Windows x64 版本，有两种选择：

- **安装版**（`DeepSeek-Harness-Desktop-Setup-<版本>-x64.exe`）：像安装 QQ、微信一样跟着向导走，装完从桌面或开始菜单打开。推荐大多数人使用。
- **便携版**（`DeepSeek-Harness-Desktop-Portable-<版本>-x64.exe`）：免安装，下载后双击就能运行，适合临时使用或放进 U 盘。

> 小提示：Windows 或浏览器可能提示“该文件来自互联网”。只要它来自上面的 GitHub Releases 页面，就可以放心运行。

## 第一次使用

1. 双击启动 DeepSeek Harness Desktop。
2. 第一次启动要准备运行环境，可能会多等一会儿，请耐心等待。
3. 打开后就是 Harness 工作台：在这里创建会话，和 AI 对话或安排任务。
4. 关闭窗口即退出，应用和后台服务会一起结束。

## 插件商店：给工作台添加新功能

和手机上的应用商店类似，Harness 工作台内置了一个**插件商店**，可以给工作台添加新功能（比如记忆、工具等）。

怎么打开：点击工作台上的**设置**按钮，进入**插件**，再切换到**插件商店**标签页。

- **浏览与搜索**：可以按分类浏览，也可以在搜索框按名称、作者或功能搜索插件。
- **安装插件**：找到插件后点击**安装**，在弹出的确认窗口勾选“我已了解这是第三方插件”（意思是这个插件不是官方开发的，安装前请确认它可信），再点击**确认安装**。
- **重启生效**：安装完成后需要重启应用，新插件才会加载。
- **查看已安装插件**：切换到**插件列表**标签页，可以查看当前已经安装的插件。

> 提醒：商店里的插件大多由社区开发者制作。安装前先看看插件的介绍、来源和评分，确认可信再安装。

## 关于自动更新

- 应用会在后台悄悄检查更新，下载并验证后，**下次启动时自动生效**，不需要重新安装。
- 如果更新后启动失败，会自动回滚到上一个可用版本。
- 应用本身的大版本更新，需要去 Releases 页面手动下载。

## 常见问题

### 一直停在加载页面

首次启动需要准备本地服务，会比较慢。等很久没反应就关闭重开；如果出现错误页面，可以点“打开日志”查看原因。

### 更新后打不开了

应用会自动回滚到上一个可用版本。仍然失败的话，在错误页面点“打开日志”，并在提 Issue 时附上日志内容。

### 想重置本地数据

退出应用后，把 `%APPDATA%\DeepSeek Harness` 文件夹备份再删除，即可重置设置、会话和日志。此操作不可恢复，删除前请确认不需要里面的数据。

## 数据和日志在哪里

- Harness 设置与会话：`%APPDATA%\DeepSeek Harness\harness-home-v2`
- 桌面端日志：`%APPDATA%\DeepSeek Harness\logs`
- 内核版本与更新文件：`%LOCALAPPDATA%\DeepSeek Harness\kernel-runtime`

主要日志文件：

- `desktop.log`：应用启动与更新记录
- `harness.stdout.log`、`harness.stderr.log`：Harness 运行时的输出和错误
